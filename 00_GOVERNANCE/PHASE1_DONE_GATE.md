## Market
- [ ] Initial ICP selected
- [ ] Initial practice area selected

- [ ] Switching objections understood

## Product
- [ ] First wedge selected
- [ ] V1 outcome written in one sentence
- [ ] Automation/human boundary defined
- [ ] Measurable target set
- [ ] NOT-IN-V1 list created

## Technical
- [ ] Required Proclaim access feasible
- [ ] Required Microsoft access feasible
- [ ] Data flows understood
- [ ] Major security risks identified

## Commercial
- [ ] Buyer identified
- [ ] ROI model exists
- [ ] Pricing hypothesis exists
- [ ] Credible pilot candidate exists

## Kill/pivot rule
If the problem is not repeated, expensive, measurable and buyable, do not force the original wedge.
