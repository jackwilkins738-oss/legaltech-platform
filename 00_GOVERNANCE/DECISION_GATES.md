# DECISION GATES

## Gate A — Market
Pass if:
- problem exists across multiple firms
- buyer is identifiable
- value is meaningful

## Gate B — Wedge
Pass if:
- narrow
- measurable
- frequent
- deployable alongside Proclaim
- manageable risk
- expansion path

## Gate C — Technical feasibility
Pass if:
- Proclaim access works
- Microsoft integration works
- required data flows are available
- no unacceptable architectural blocker

## Gate D — Security feasibility
Pass if:
- tenant isolation model credible
- data processing acceptable
- AI providers/processors acceptable
- customer security review can plausibly be passed

## Gate E — Pilot
Pass if:
- measurable improvement
- acceptable exceptions
- strong adoption
- customer wants continuation

## Gate F — Commercial
Pass if:
- customer pays
- ACV can support onboarding/security
- gross-margin path is strong

## Gate G — Replacement
Do not attempt full Proclaim replacement until:
- customers actively want to consolidate into our product
- migration has been rehearsed
- core operational features are mature
- enterprise support/security exists
