# CONCURRENCY, INTERRUPTIONS AND TASK BOUNDARIES

## Start
Task starts at the first purposeful action caused by the trigger.

## End
Task ends when the intended output/state change is complete or responsibility is handed off.

## Interruptions
Pause active timing for unrelated interruptions where timing can be recovered. If not recoverable, flag and exclude from timing average.

## Concurrent tasks
Never count the same minute twice in labour economics. Note co-occurring work separately.

## Batching
Record batch size and calculate per-item effort only when the batch process is genuinely homogeneous.

## Search/navigation
Count search/navigation when it is required to complete the task; do not discard it as “overhead” if it is part of the current workflow.
