# MODULE / LICENCE / CONFIGURATION INVENTORY

Capture:
- core Proclaim licence tier/user count;
- practice modules;
- Accounts;
- document/email modules;
- portals/forms;
- reporting/BI;
- API/integration entitlements;
- third-party integrations;
- modules bought but unused;
- module desired but not licensed;
- implementation owner;
- last upgrade/change date.

Reason: an opportunity may be a procurement/licensing issue rather than missing technology.
