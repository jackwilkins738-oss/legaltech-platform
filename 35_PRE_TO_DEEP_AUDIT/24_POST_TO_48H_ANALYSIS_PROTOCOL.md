# POST-TO 48-HOUR ANALYSIS PROTOCOL

## First pass
- freeze raw observations;
- run data-quality checks;
- document coverage/limitations;
- separate continuous vs targeted samples;
- exclude contaminated timing;
- define Task Family × Role.

## Second pass
- triangulate frequency/population;
- run root-cause review;
- identify positive Proclaim controls;
- compare observed/user-reported/system evidence;
- rank by active burden, consequence, standardisation, feasibility, automation ceiling.

## Third pass
- falsify each pre-registered hypothesis;
- identify top 3 opportunities and top 3 reasons not to pursue them;
- specify next evidence needed;
- only then change product roadmap.
