# SATURATION / STOP RULES

A task family is sufficiently understood for provisional analysis when:
- task boundary is stable;
- normal path is consistent;
- major variants/exceptions identified;
- additional observations no longer add a new material system/handoff/root cause;
- timing range is not being driven by obvious interruptions;
- volume source is independently identified;
- root cause has at least one corroborating source beyond the observed user where practical.

Continue observing when:
- timing variance remains unexplained;
- users perform materially different variants;
- exceptions are frequent;
- the task crosses roles;
- system behaviour differs by matter type/stage;
- native Proclaim capability is disputed.

Stop collecting targeted repeats merely because a candidate looks attractive.
