# WORKER MONITORING / PRIVACY IMPLEMENTATION CHECKLIST

The ICO treats both systematic and occasional worker monitoring as monitoring and requires lawful, fair, transparent, purpose-limited processing. Employers should use the least intrusive method, document purpose/lawful basis, consider DPIA requirements, and retain data only as necessary.

Before TO:
- firm/manager authorisation;
- clearly defined workflow-research purpose;
- tell observed workers what is being captured/why, unless the firm has a lawful process that says otherwise;
- no covert audio/video/screenshots;
- minimise names and employee-performance data;
- no individual productivity rankings;
- retention/deletion plan;
- escalation to firm privacy/DPO if systematic monitoring or screenshots/log exports expand scope.
