# SYSTEM DATA REQUEST PACK

Highest-value P0 data, if authorised and reasonably available:
- matter counts by case type/practice/stage;
- new/closed matters by month;
- open diary/tasks by action type/owner/age;
- history/email/document actions by type/day;
- active users by role/team/case type.

P1:
- Proclaim support tickets;
- change-request backlog;
- training records;
- mailbox/shared-mailbox volumes;
- client update/call/complaint volumes;
- overtime/temp staff/vacancies.

P2:
- stage/cycle times;
- external-party response times.

Do not delay TO waiting for all of these. Their purpose is validation, not permission to observe.
