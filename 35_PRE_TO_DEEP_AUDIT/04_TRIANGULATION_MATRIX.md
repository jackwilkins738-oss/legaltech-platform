# TRIANGULATION MATRIX

For each important task family, seek up to four evidence channels:
1. **Observation** — what actually happens and active time.
2. **System/report** — frequency, volume, backlog, stage distribution.
3. **User/manager report** — exceptions, why, consequence, historical context.
4. **Configuration/technical review** — whether Proclaim/M365 already can solve it and what blocks adoption.

A strong software-opportunity claim should ideally survive all four.

If they disagree, investigate the disagreement rather than averaging it away.
