# OPERATIONS, SUPPORT AND SRE

## Reliability
Define before production:
- SLOs
- SLIs
- uptime target
- RPO
- RTO
- backup schedule
- backup retention
- restore tests
- failover
- dependency outage behaviour
- queue backlog behaviour
- AI provider outage behaviour
- Microsoft outage behaviour

## Support
Design:
- L1
- L2
- L3
- security escalation
- incident severity
- customer communication
- status page
- knowledge base
- support-access controls
- break-glass access

## Avoid Proclaim complaint pattern
A key opportunity is not only software quality but operational quality:
- transparent status
- faster support
- self-service configuration
- strong docs
- predictable change process
- clear pricing for implementation work
