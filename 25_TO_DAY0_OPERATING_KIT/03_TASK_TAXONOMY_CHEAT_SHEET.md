# TASK TAXONOMY CHEAT SHEET

| Code | Use when | Example |
|---|---|---|
| FILE | Save/file an email or document | Drag email into Proclaim history |
| MATCH | Determine correct matter | Search reference/name |
| CLASSIFY | Decide what item is | Medical record vs liability response |
| EXTRACT | Pull facts/dates/amounts | Read offer amount |
| DATA_ENTRY | Enter/update fields | Re-key policy number |
| CREATE_TASK | Create work/action | Add chase action |
| CHASE | Follow up external/internal party | Chase hospital records |
| CLIENT_UPDATE | Update/request from client | Send status email |
| DRAFT | Prepare correspondence/document | Draft letter |
| REVIEW | Review file/work | Supervisor file review |
| DEADLINE | Identify/manage a due date | Court order date |
| EVIDENCE | Request/manage evidence | Medical records |
| INTAKE | New enquiry/onboarding | Initial client details |
| BILLING | Cost/payment/admin | Cost entry |
| SEARCH | Find information | Search history/documents |
| REPORT | Produce management/report output | Caseload report |
| OTHER | Genuine uncategorised task | Explain in notes |

## Multi-step example
Email arrives:
1. MATCH
2. CLASSIFY
3. FILE
4. EXTRACT
5. CREATE_TASK

If these happen as one uninterrupted micro-workflow, record the dominant event and note steps.
If independently measurable, split them.
