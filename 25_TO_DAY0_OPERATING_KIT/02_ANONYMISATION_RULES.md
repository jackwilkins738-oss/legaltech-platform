# TO ANONYMISATION RULES

## Never put in the research workbook
- client name
- DOB
- address
- phone/email
- real matter number
- insurer claim reference
- medical diagnosis/details
- witness name
- defendant name where identifying
- screenshots containing client data
- copied email/document text
- bank/payment information

## Use instead
Matter:
`MAT-001`, `MAT-002`

External party:
`INSURER-A`, `HOSPITAL-B`, `EXPERT-C`

Document:
`MEDICAL_RECORDS`, `COURT_ORDER`, `LIABILITY_RESPONSE`

Generic description:
"Insurer liability response arrived and admin filed it."

## Screenshots
Do not take unless:
- the firm authorises it;
- identifiable/confidential content is removed;
- storage path is approved.

## Notes
We need process facts, not client facts.

Good:
"Admin manually rekeys accident date from email into Proclaim."

Bad:
"John Smith, accident 14/2/26, Aviva ref 38485..."

## If accidental personal data is captured
Remove it from research notes immediately and follow the firm's approved handling process if necessary.
