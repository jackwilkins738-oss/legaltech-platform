# FIRST 30 EVENTS ANALYSIS

## Trigger
Run once roughly 30 task events are captured.

## Produce
### 1. Top task categories by observed active minutes
This reveals immediate labour concentration.

### 2. Top task categories by annualised capacity value
Uses frequency × people × minutes × loaded cost.

### 3. Context-switching leaders
Highest system switches and systems touched.

### 4. Judgement distribution
How much work is:
- deterministic
- contextual
- legal judgement.

### 5. Exception/rework
Which task families generate exceptions or corrections?

### 6. External waiting
Which tasks create the longest delay even if active labour is small?

### 7. Top three provisional wedge candidates
For each:
- evidence observed
- missing evidence
- reason it may win
- reason it may fail.

## Caution
Thirty observations identify hypotheses.
They do not establish final annual averages.
