# PROCLAIM ENVIRONMENT QUESTIONNAIRE

## Ask the internal Proclaim/IT person

### Environment
- exact Proclaim version?
- CaseMatters Evo in use/planned?
- hosted where/by whom?
- database/platform version if known?
- number of users?
- offices/branches?

### Modules
- case management
- accounts
- Task Server
- document services
- reporting
- web/API modules
- anything practice-specific

### API/integration
- REST available?
- SOAP available?
- licensed web services?
- API documentation?
- test environment?
- service account?
- authentication method?
- current third-party integrations?

### Current automation
- what is already automated?
- what required bespoke Proclaim development?
- what cannot currently be automated?
- what breaks most often?
- how long does a typical Proclaim change take?
- internal developer or external consultant?

### Outlook/documents
- old or new Outlook?
- how are emails filed?
- how are attachments handled?
- common naming rules?
- common failure/workaround?

### Workflows
- main PI case types
- task/action types
- custom stages
- key custom fields
- information barriers/restricted matters

### Future
- Evo migration plans?
- planned upgrades?
- current Access support issues?
