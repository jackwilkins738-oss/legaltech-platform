# Dry run and TO-day logistics

## Mandatory dry run
Before the live study, run 20–30 minutes using:
- synthetic workflow examples;
- the actual device/workbook;
- the actual taxonomy;
- start/end timestamps;
- post-event enrichment.

Pass if the observer can keep up without:
- missing task boundaries;
- repeatedly asking the subject to wait;
- writing client content;
- losing timestamps.

## Practical controls
- charge device;
- disable distracting notifications;
- use an offline/local working copy if connectivity is uncertain;
- have a backup copy/template;
- keep clock/timezone consistent;
- no screenshots/recordings unless separately authorised;
- take observer breaks to avoid coding fatigue;
- note any period where capture quality degraded.

## Abort/pause
Pause the study if:
- a worker objects or needs clarification;
- observation begins collecting client-identifiable content;
- the observer cannot keep up;
- task boundaries become ambiguous;
- an unexpected privacy/security issue arises.
