# Two-pass live capture

The current full workbook is intentionally rich, but trying to populate every field during a task can overload the observer and distort the workflow.

## Pass 1 — live
Capture only:
- Event ID
- Session ID
- start timestamp
- end timestamp
- role
- task family
- primary system
- normal/exception flag
- interruption flag
- obvious system wait
- short neutral note

Do not interrogate the worker mid-task.

## Pass 2 — immediate enrichment
At the end of the task or natural break, enrich:
- practice/stage
- complexity
- reading/thinking time if distinguishable
- external wait
- handoffs
- copy/paste/rekey/search
- progression block
- value class
- exception cause
- native Proclaim capability
- cheapest fix
- root cause
- sanitised direct quote
- observer inference
- inclusion decision

## Why
Continuous-observation studies can become unreliable when the observer is overloaded by data entry. The observation interface must preserve attention on the workflow.
