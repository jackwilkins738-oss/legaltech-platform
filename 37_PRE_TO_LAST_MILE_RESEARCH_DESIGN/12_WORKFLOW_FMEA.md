# Workflow FMEA for rare/high-impact work

Time-motion observation favours frequent events. It can miss rare failures with serious consequences.

For candidate workflows capture:
- failure mode;
- consequence;
- severity;
- occurrence evidence;
- detectability;
- current control;
- whether automation reduces risk;
- whether automation creates a new failure mode;
- required human control.

Examples:
- wrong-matter filing;
- missed deadline;
- incorrect external recipient;
- unreviewed high-impact draft;
- missing evidence before stage progression;
- duplicate external action.

Do not infer occurrence rates from one observed rare event. Use incident/complaint/support data where available.
