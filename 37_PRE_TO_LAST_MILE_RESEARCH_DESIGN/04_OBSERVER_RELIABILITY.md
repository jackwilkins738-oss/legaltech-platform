# Observer reliability and calibration

## Problem
A precise stopwatch does not help if two observers disagree about:
- what task occurred;
- when it started/ended;
- what category it belongs to;
- the sequence of fragmented tasks.

Published workflow time-motion methods treat observer reliability as a substantive methodological issue, not a footnote.

## Minimum pre-TO calibration
Where practical:
1. Have two people independently classify/time the same 10–20 synthetic or non-sensitive workflow examples.
2. Compare task naming, boundaries, duration and sequence.
3. Discuss disagreements.
4. Update taxonomy/boundary rules.
5. Repeat a small sample until disagreements are low enough for practical use.

## If only one live observer exists
Have a second person independently code a sample of **sanitised event notes** after the session. This does not create true live inter-observer reliability, but it tests classification ambiguity.

## Report honestly
Do not describe a single-observer study as observer-reliability validated unless a real reliability exercise occurred.
