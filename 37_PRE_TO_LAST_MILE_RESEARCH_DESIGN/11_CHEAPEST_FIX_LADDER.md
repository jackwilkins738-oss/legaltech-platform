# Cheapest-fix ladder

Before calling any observed pain a software opportunity, test solutions in this order:

1. Clarify/standardise SOP.
2. Training/adoption.
3. Existing Proclaim configuration.
4. Existing licensed module/integration.
5. Template/report/profile change.
6. Microsoft 365 rule/Power Automate/simple workflow.
7. Deterministic API/rules integration.
8. RPA only where APIs are unavailable and controls are acceptable.
9. AI-assisted workflow.
10. Agentic automation.
11. New standalone product capability.

## Decision question
**What is the cheapest safe intervention that removes the problem?**

If training or configuration solves the issue economically, that is evidence against building a new product feature.

AI should not be chosen because it is available.
