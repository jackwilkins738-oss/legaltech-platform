# Robust statistics and uncertainty

## Do not make the mean the headline
Workflow durations are often skewed by:
- exceptions;
- rework;
- complex matters;
- interruptions;
- slow systems.

For each Task Family × Role report where data permits:
- N
- median
- P25
- P75
- P90
- mean
- min/max
- normal-path N
- exception N

## Frequency
Where continuous observation is used, report events per observed hour with the session denominator. Do not infer daily prevalence from targeted repeats.

## Small N
Five examples can support a provisional workflow hypothesis. It does not create a statistically stable time estimate.

## Confidence intervals
If enough data is later collected, use bootstrap intervals rather than assuming a normal distribution of task time.

## Annualisation
Decision-grade annualisation requires independently validated volume/headcount, not observation-derived convenience estimates.
