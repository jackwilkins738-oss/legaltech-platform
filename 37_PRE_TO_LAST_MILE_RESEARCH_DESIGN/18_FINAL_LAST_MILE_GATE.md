# Final last-mile gate

## Blockers before live observation
The TO should not start until all P0 items below are satisfied:

- [ ] firm/manager authorisation confirmed;
- [ ] worker transparency/briefing route confirmed;
- [ ] no covert recording;
- [ ] clean-room/anonymisation rules understood;
- [ ] 20–30 minute dry run passed;
- [ ] start/stop/timing precision rules understood;
- [ ] live capture sheet is usable without disrupting the subject;
- [ ] raw-session freeze/backup method known.

## Strongly recommended, not hard blockers
- [ ] second-person observer calibration/review;
- [ ] P0 system-data requests raised;
- [ ] process-mining extract fields discussed with IT/Proclaim admin;
- [ ] metadata-quality sample planned if authorised;
- [ ] process/change-owner map started;
- [ ] observer uses neutral/blinded prompt pack.

## During study
- [ ] record session denominator;
- [ ] distinguish normal/exception paths;
- [ ] distinguish system wait vs external wait;
- [ ] do not double-count concurrency;
- [ ] do not derive frequency from targeted repeats;
- [ ] ask explanatory questions after the task;
- [ ] capture unexpected/disconfirming evidence.

## Before any product conclusion
- [ ] robust statistics, not mean only;
- [ ] independent volume validation;
- [ ] root-cause review;
- [ ] cheapest-fix ladder;
- [ ] Proclaim positive-control check;
- [ ] FMEA for high-risk candidate;
- [ ] metadata/data-access feasibility;
- [ ] transferability test;
- [ ] study limitations disclosed.

If any material conclusion depends on a missing item above, label it provisional.
