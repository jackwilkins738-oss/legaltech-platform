# WEDGE HYPOTHESES

## Rule
These are hypotheses until TO data ranks them.

## Wedge A — Intelligent inbound legal operations
Input:
- email
- attachment
- uploaded document

System:
- identify likely matter
- classify correspondence/document
- extract structured information
- detect dates
- detect required actions
- identify missing information
- recommend/create task
- file correctly
- prepare acknowledgement/follow-up
- audit every step

Human:
- reviews low-confidence/high-impact decisions

### Why attractive
High frequency, highly measurable, expansion path into full workflow.

## Wedge B — Proclaim exception queue
System continuously looks for:
- overdue tasks
- missing documents
- unanswered emails
- stalled cases
- inconsistent fields
- approaching deadlines
- workflow failures

User sees only exceptions requiring intervention.

### Why attractive
Moves from passive case management to active operations management.

## Wedge C — Modern Proclaim operations layer
Browser UI over selected Proclaim data:
- universal search
- task queue
- matter summary
- documents
- communications
- next actions
- management reporting

### Risk
Can become a large integration project and may duplicate CaseMatters Evo.

## Wedge D — No-code legal workflow builder
Easy visual automation without specialist Proclaim development.

### Risk
Actionstep and others already compete strongly here.
Needs exceptional differentiator.

## Wedge E — Migration engine
Automated discovery/mapping/reconciliation for firms leaving Proclaim.

### Strategic value
Migration is a major barrier to replacement.
Could become a moat.
But harder to sell as the very first standalone product.

## Current provisional ranking
1. Intelligent inbound operations
2. Exception queue
3. Migration tooling as internal strategic capability
4. Operations layer
5. Workflow builder

TO data can overturn this.
