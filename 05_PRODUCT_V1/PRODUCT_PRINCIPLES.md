# PRODUCT PRINCIPLES

1. Do not build Proclaim with nicer colours.
2. Minimise human touches, not just clicks.
3. Human judgement and administrative execution are separate.
4. Automation must be explainable.
5. Every automated external action has an explicit approval policy.
6. Exception-based work beats giant task lists.
7. Search should be universal and permission-aware.
8. Information should not need to be entered twice.
9. Email/documents should become structured events automatically.
10. Workflow changes should be testable, versioned and reversible.
11. Configuration should not require obscure specialist knowledge.
12. Product speed is a feature.
13. Browser-first.
14. Strong keyboard workflows for heavy users.
15. Every feature has a measurable operational outcome.
16. Security is part of UX, not a separate layer.
17. AI is an untrusted component, not an authority.
18. Migration/export are first-class product capabilities.
19. Customer data must never become training data by default.
20. The product should be replaceable/exportable even if that reduces lock-in.
