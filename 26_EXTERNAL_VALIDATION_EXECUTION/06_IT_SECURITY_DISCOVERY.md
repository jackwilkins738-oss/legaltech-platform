# IT / SECURITY DISCOVERY

## Microsoft
- Entra tenant?
- shared mailboxes?
- Graph application permissions accepted?
- Exchange RBAC for Applications?
- SSO/SAML/OIDC?
- SCIM?
- conditional access?

## Deployment
- SaaS allowed?
- preferred cloud?
- UK/EU residency?
- IP allowlist/private network?
- SIEM integration?
- log retention?

## Supplier review
- Cyber Essentials?
- ISO 27001 required?
- pen-test report?
- insurance?
- DPA?
- subprocessor list?
- AI provider restrictions?

## Data
- special-category data;
- retention;
- support access;
- information barriers;
- encryption requirements.

## Pilot
Ask:
"What is the smallest technically acceptable pilot configuration?"

This is more useful than asking whether the firm has a 50-page enterprise security policy.
