# WHO TO INTERVIEW

## Operations / COO
Ask about:
- bottlenecks;
- staffing;
- throughput;
- supervision;
- exceptions;
- change speed;
- ROI.

## Head of PI / Claims
Ask:
- repeated admin;
- evidence delays;
- client updates;
- offers;
- supervision;
- file progression.

## Proclaim / Applications Manager
Ask:
- what Proclaim already does well;
- what is technically possible;
- change backlog;
- configuration complexity;
- API/integration;
- failure modes;
- Evo.

## IT / Security
Ask:
- Graph access;
- service identities;
- app permissions;
- security review;
- deployment;
- data region;
- SSO;
- logs;
- supplier requirements.

## Team Leader / File Handler
Ask:
- actual daily workflow;
- manual workarounds;
- exceptions;
- rework;
- what staff avoid doing in Proclaim.

## Economic buyer
Usually:
- managing partner;
- CEO;
- COO;
- finance/ops director.

Do not confuse an enthusiastic user with someone able to approve a pilot.
