# TRUST CENTRE CONTENT MAP

## Purpose
Make security/procurement self-service.

Competitors such as Clio publicly market:
- encryption
- role-based controls
- SOC 2
- backups
- MFA
- data residency/security assurances

We need equivalent transparency as maturity grows.

## Public
- security overview
- privacy overview
- hosting regions
- subprocessors
- uptime/status
- vulnerability disclosure
- incident contact
- AI security principles
- data-use/training position
- certifications

## NDA / customer portal
- pen-test executive summary
- ISO certificate
- Cyber Essentials evidence
- detailed architecture
- BCP/DR summary
- incident-response summary
- security questionnaire
- latest audit reports where shareable

## Core statements
Must be precise:
- encryption
- backup
- SSO/MFA
- tenant isolation
- AI provider retention
- training
- subprocessor
- incident notification
- data deletion/export

Do not make vague claims such as "bank-grade security."

## Evidence linkage
Every trust claim maps to:
- policy
- technical control
- evidence owner
- last verified date
