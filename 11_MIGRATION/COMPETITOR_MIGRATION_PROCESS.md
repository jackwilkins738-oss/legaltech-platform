# COMPETITOR MIGRATION PROCESS

## Clio
Public UK migration flow:
1. onboarding call
2. data export
3. data upload/import
4. customer review
5. go live

Clio says:
- migrations from 70+ vendors in previous year
- common migration may be complimentary
- broader range includes contacts, matters, calendars, tasks, unbilled time/expenses
- complex migration may require paid partner
- duration can range days to weeks

## Actionstep
Implementation:
1. plan
2. design
3. build
4. test
5. deploy

Actionstep states implementation commonly takes 6–12 weeks depending on:
- firm size
- migration
- workflows
- training
- customer stakeholder availability

Imports use templates/mapping and recommend test records first.
Rollback has limitations once imported records are edited.
