# PAID PILOT STRUCTURE

## Principle
Pilot is a commercial experiment, not free consulting.

## Scope
Example:
- one PI team
- 10–30 users
- one/few mailboxes
- selected matter types
- inbound email/document workflow

## Duration
Enough volume to measure.
Typically several weeks, but define by processed-event target rather than arbitrary time alone.

## Setup
- DPA
- security review
- named stakeholders
- technical access
- baseline
- configuration

## Success criteria
Examples:
- >X% correct matter matching
- >X% classification
- Y% reduction in manual handling
- Z hours capacity saved
- <threshold harmful errors
- zero confidentiality incidents
- user adoption target
- write-back success rate

Exact figures set after baseline/evaluation.

## Pricing
Paid.
Potential structure:
- fixed setup/pilot fee
- credited partly against annual contract if conversion

## Governance
Weekly:
- metrics
- errors
- exceptions
- feedback
- security/incident review

## End
Three outcomes:
PASS → expansion/contract
ITERATE → defined remediation
FAIL → stop/no forced sale

## No hidden production expansion
Do not silently widen:
- mailboxes
- teams
- matter types
- autonomous actions
without customer approval.
