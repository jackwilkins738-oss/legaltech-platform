# BUSINESS MODEL AND PRICING

## Avoid pricing purely on AI usage
Customer buys:
- admin capacity
- faster case progression
- lower error/rework
- operational control
- reduced system friction

## Pricing models to test
### Per user
Easy benchmark against Proclaim.
Risk: discourages broad adoption.

### Per firm / tiered platform
Good for enterprise predictability.

### Per matter
Aligns with workload but can become unpredictable.

### Automation-volume
Aligns with usage but feels like metered infrastructure.

### Hybrid recommended hypothesis
Base platform fee + user/volume tier + implementation/migration.

## Early target economics
Do not commit yet, but model:
- £15k ACV
- £30k ACV
- £60k ACV
- £100k ACV

For each calculate:
- support burden
- onboarding cost
- AI cost
- storage
- cloud
- security tooling
- sales cost
- implementation
- migration

## Economic value principle
If customer capacity value is £100k/year, charging £2k/year leaves enormous value uncaptured and may signal low enterprise credibility.
If value is £10k/year, a £50k contract fails.

Price follows measured economics.
