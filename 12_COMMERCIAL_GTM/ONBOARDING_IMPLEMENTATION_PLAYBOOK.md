Make onboarding repeatable and eventually mostly product-driven.

## Phase 1 — Discovery
- stakeholders
- workflows
- Proclaim environment
- Microsoft tenant
- mailboxes
- security
- data
- success metrics

- DPA
- subprocessors

- SSO

- customer review

## Phase 3 — Configuration
- teams
- matter mappings
- document taxonomy
- task mapping
- workflows
- approval policies

## Phase 4 — Integration test
- Graph
- Proclaim
- end-to-end test
- failure scenarios

- volume
- handling time
- error/rework
- backlog

- mailbox
- matter types
- workflow

- accuracy
- exceptions
- adoption
- ROI
- incidents
- technical issues

## Phase 8 — Expansion
Only if gate passed.

## Implementation KPI
- days to first value
- founder hours/customer
- engineering hours/customer
- customer hours
- configuration reuse %
- defects
