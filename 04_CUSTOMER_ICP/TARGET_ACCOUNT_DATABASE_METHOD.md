# TARGET-ACCOUNT DATABASE METHOD

## Goal
Create a ranked database of UK firms likely to:
- use Proclaim
- run high-volume PI/claims work
- have enough operational scale
- experience meaningful admin friction
- afford a £20k–£100k+ software relationship

## Evidence fields

### Firm identity
- firm name
- website
- Companies House name where relevant
- headquarters
- branches
- practice areas
- estimated headcount

### Proclaim evidence
- evidence level A/B/C
- exact evidence
- source
- date
- product context
- confidence
- last revalidated

### Scale evidence
- employee count
- legal admin hiring
- file-handler hiring
- team structure
- caseload evidence
- branch count

### Operational signals
- Proclaim jobs
- admin jobs
- legal secretary roles
- PI file handler roles
- operations vacancies
- IT/applications vacancies
- automation/digital transformation roles

### Commercial signals
- growth
- acquisitions
- merger
- new office
- recruitment volume
- case-volume claims
- awards/growth statements

### Buyer map
- managing partner/CEO
- COO
- head of operations
- IT director
- practice head
- applications manager
- compliance/DPO

## Scoring

### Proclaim confidence — 30%
5 current direct evidence
4 recent strong indirect
3 historical direct
2 indirect/stale
1 weak
0 none

### Workflow density — 25%
5 high-volume PI/claims with large case teams
1 bespoke low-volume work

### Company size — 15%
Best initial hypothesis:
50–250 Proclaim users

### Trigger — 15%
Examples:
- active Proclaim hiring
- migration
- expansion
- support role
- digital transformation

### Reachability — 10%
Clear buyers/directors/contact routes.

### Strategic fit — 5%
Potential expansion across branches/practice areas.

## Validation workflow
1. find evidence
2. save citation/source
3. score
4. identify buyer
5. reverify Proclaim use
6. only then outreach

## Current market signals
Current UK PI job listings still mention Proclaim as beneficial/desired.
A current public Proclaim integration provider says it has integrated systems for over 50 solicitor firms.

## Important
Do not represent "likely Proclaim user" as verified until confirmed.
