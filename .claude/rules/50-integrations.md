# Integration rules
- Prefer official/current API/platform evidence.
- Real customer Proclaim configuration outranks generic documentation.
- External writes must be idempotent, auditable and reconciled.
- Separate read, write and send permissions where practical.
- Do not assume an integration/licence/permission exists until verified.
