# DEMO SCRIPT / DEMO ENVIRONMENT

## Rule
Never demo with real client data without explicit approved environment.

Use synthetic PI matter corpus.

## 12-minute workflow demo

### 1. Current pain — 60 sec
"Email arrives. Staff identify matter, file it, interpret it, create work, then supervisors chase exceptions."

### 2. Inbound — 90 sec
Show synthetic insurer email and attachment.

### 3. Understanding — 2 min
Show:
- candidate matter;
- signals;
- class;
- extracted facts;
- source citations.

### 4. Exception — 2 min
Use deliberately ambiguous sample.
Show system refusing to auto-file.

### 5. Human decision — 1 min
Confirm correct matter.

### 6. Proclaim — 2 min
Show test/mock write + read-back verification.

### 7. Audit — 1 min
Who/what/model/workflow/outcome.

### 8. Management value — 90 sec
Show handling time, review rate, exceptions.

## Never demo
- fake "100% accuracy";
- autonomous legal advice;
- fabricated customer savings;
- uncontrolled production integration.

## Demo reset
One command/script should restore the synthetic demo tenant deterministically.
