# SECURITY QUESTIONNAIRE RESPONSE LIBRARY

## Purpose
Maintain pre-approved factual answers; never improvise security claims in sales.

## Company/security governance
Answer with:
- named security owner;
- policy review cycle;
- risk register;
- incident process.

## Certifications

- achieved;
- in progress;
- planned.

Never say "ISO compliant" as substitute for certification.

## Incident
ICO-reporting assessment where relevant, customer contractual notification, evidence preservation.

UK GDPR reportable breaches must be notified to the ICO without undue delay and, where feasible, within 72 hours of awareness.

Source:
https://ico.org.uk/for-organisations/report-a-breach/personal-data-breach/personal-data-breaches-a-guide/
