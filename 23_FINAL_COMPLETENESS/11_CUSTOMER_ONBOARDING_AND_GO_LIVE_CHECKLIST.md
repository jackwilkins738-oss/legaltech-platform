# CUSTOMER ONBOARDING / GO-LIVE CHECKLIST

## Commercial
- signed Order/SOW;
- MSA/DPA/security schedule complete;
- insurance requirement met.

## Governance
- executive sponsor;
- ops owner;
- IT owner;
- privacy/security;
- user champions.

## Technical
- SSO;
- SCIM if required;
- mailbox scope;
- Proclaim test;
- mappings;
- monitoring;
- backups;
- support contacts.

## Security/privacy
- DPIA/customer assessment supported;
- subprocessors disclosed;
- retention;
- support access;
- information barriers;
- logging;
- incident path.

## Product
- workflow configured;
- thresholds;
- approvals;
- test fixtures;
- practice pack;
- user roles.

## Validation
- synthetic E2E;
- customer UAT;
- negative/security tests;
- rollback;
- audit.

## Training
- users;
- leaders;
- IT/support.

## Baseline
capture before launch:
- volume;
- handling minutes;
- error/rework;
- queue age.

## Go-live approval
Vendor product/technical/security + customer ops/IT.

No single founder can waive a release-blocking security control.
