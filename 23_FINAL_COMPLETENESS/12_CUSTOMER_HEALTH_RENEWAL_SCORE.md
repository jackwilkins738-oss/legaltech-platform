# CUSTOMER HEALTH / RENEWAL SCORE

## Dimensions
Score 0–5:
- adoption;
- measurable value;
- workflow accuracy;
- connector health;
- support health;
- champion strength;
- executive sponsorship;
- roadmap fit.

## Red flags
- usage down 30%+;
- champion leaves;
- high correction rate;
- no measured ROI;
- Proclaim/Evo migration changes;
- repeated Sev1/2;
- security concern;
- unresolved roadmap blocker.

## Action
GREEN:
expand/value review.

AMBER:
named recovery plan.

RED:
executive intervention / honest renewal risk.

## Renewal review
90–120 days before renewal:
- value;
- usage;
- unresolved problems;
- security updates;
- pricing;
- expansion;
- exit readiness.

Never create hostage retention through export difficulty.
