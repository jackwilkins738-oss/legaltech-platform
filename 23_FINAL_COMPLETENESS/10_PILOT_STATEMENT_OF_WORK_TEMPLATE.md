# PAID PILOT — STATEMENT OF WORK TEMPLATE

> Commercial template for counsel review; not legal advice.

## Objective
Test one defined workflow and quantify value/safety.

## Scope
- named team;
- named mailbox(es);
- named matter types;
- permitted actions;
- excluded actions.

## Integrations
- Microsoft Graph;
- Proclaim;
- optional others.

## Data
- data categories;
- special-category data;
- regions;
- retention;
- customer responsibilities.

## Deliverables
- configured pilot;
- training;
- weekly metrics;
- end report;
- export/deletion if pilot ends.

## Success metrics
- handling time;
- review rate;
- accuracy;
- writeback;
- adoption;
- zero material confidentiality incident.

Set numerical thresholds only after baseline.

## Duration
Define start/end and extension process.

## Price
Fixed pilot fee + explicitly stated included implementation.

## Customer dependencies
- access;
- technical contacts;
- representative samples;
- timely approvals.

## Governance
weekly review, incident contacts, change process.

## Exit
PASS / ITERATE / FAIL.
No automatic scope expansion.
