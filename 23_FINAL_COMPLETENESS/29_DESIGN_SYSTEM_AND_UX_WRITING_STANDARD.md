# DESIGN SYSTEM / UX WRITING STANDARD

## Product personality
Calm, precise, operational.
Never theatrical AI language.

## Terminology
Prefer:
- "Suggested matter"
- "Needs review"
- "Source"
- "Why this was suggested"
- "Confirmed by"

Avoid:
- "AI knows"
- "guaranteed"
- "risk-free"
- "100% accurate"

## Status
Every status uses:
- text;
- icon where useful;
- colour as supplemental only.

## Dangerous actions
Use:
- clear consequence;
- explicit object/matter;
- confirmation for high impact;
- no ambiguous primary button.

## AI output
Show:
- source;
- confidence/reason where meaningful;
- verification state;
- model-generated indicator where relevant.

## Accessibility
WCAG 2.2 AA target.
Keyboard complete.
Focus visible.
No colour-only priority.

## Empty/error states
Explain:
- what happened;
- whether work is safe;
- what user can do;
- support trace ID where appropriate.
