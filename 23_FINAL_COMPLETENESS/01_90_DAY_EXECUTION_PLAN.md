# 90-DAY EXECUTION PLAN

## Objective
Move from pre-build research to a paid, evidence-backed pilot without prematurely building a full PMS.

## Days 1–10 — Evidence + feasibility
Founder/commercial:
- run TO study;
- 5–10 external interviews;
- score workflows;
- identify 1–3 pilot candidates.

Technical:
- Graph test-tenant spike;
- safe document pipeline;
- synthetic matching/eval harness;
- obtain authorised Proclaim test information.

Company:
- company-owned GitHub/cloud/email;
- founder/IP paperwork;
- ICO fee self-assessment/registration if required;
- security baseline.

Gate:
one workflow must show meaningful frequency/value AND credible technical path.

## Days 11–30 — Technical proof
Build only:
- tenant/auth/audit/idempotency;
- Graph ingest;
- document quarantine;
- canonical matters/communications;
- matching;
- exception review;
- Proclaim test adapter/writeback if authorised.

Commercial:
- turn strongest workflow into quantified pilot proposal;
- security discovery with first candidate.

Gate:
synthetic E2E passes and Proclaim path is GREEN/AMBER.

## Days 31–60 — Pilot-ready product
- harden tenancy/auth;
- monitoring;
- backup;
- support runbook;
- customer configuration;
- pilot reporting;
- security tests;
- customer onboarding.

Run real representative evaluation under agreed privacy controls.

Gate:
pilot engineering/security/governance checklist passes.

## Days 61–90 — Paid pilot
- deploy bounded team/workflow;
- baseline and measure;
- weekly value review;
- capture corrections/exceptions;
- no silent scope expansion.

End states:
PASS → annual/expanded contract.
ITERATE → one defined remediation cycle.
FAIL → stop/reselect wedge.

## Founder rule
Do not let a customer pull the team into:
- full accounting;
- full PMS;
- bespoke unrelated modules;
- autonomous legal advice
before the wedge is proven.
