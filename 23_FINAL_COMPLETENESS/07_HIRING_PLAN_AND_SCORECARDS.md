# HIRING PLAN & SCORECARDS

## Hiring order — evidence dependent

### 1. Senior/full-stack or backend engineer
Hire when:
- founders/Claude Code are bottlenecked;
- production pilot needs independent engineering judgement.

Score:
- secure multi-tenant SaaS;
- APIs/integrations;
- Postgres;
- queues/idempotency;
- pragmatic delivery;
- ability to review AI-generated code.

### 2. Legal operations/domain implementation
Hire when:
- >3 implementations;
- configuration/domain work exceeds founders.

Score:
- real law-firm ops;
- Proclaim/PMS understanding;
- process mapping;
- client communication;
- configuration reuse mindset.

### 3. Customer success / implementation
When repeatable onboarding exists.

### 4. Security/compliance
Internal hire later; use specialist external support earlier.

### 5. Sales
Only after founder-led repeatability.

## Interview principle
Work samples > generic interview.

Engineer:
give bounded architecture/debug review.

Legal ops:
map a realistic PI workflow and identify automation boundaries.

CS:
recover a failing pilot scenario.

## Do not hire early
- large sales team;
- generic SDR army;
- multiple managers;
- accounting-product team;
- research team.
