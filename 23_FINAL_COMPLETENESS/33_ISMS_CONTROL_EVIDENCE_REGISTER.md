# ISMS CONTROL / EVIDENCE REGISTER

## Structure
For each control:
- control ID;
- requirement/source;
- policy;
- procedure;
- technical implementation;
- evidence;
- test cadence;
- owner;
- exception;
- corrective action.

## Initial evidence examples
- MFA screenshots/config exports;
- device/MDM inventory;
- access review;
- GitHub branch protection;
- secret scan;
- backup job + restore drill;
- vulnerability scan;
- incident tabletop;
- vendor review;
- training;
- risk review.

## Rule
A policy document is not proof a control operates.

ISO readiness depends on repeated evidence and management activity, not document count.
