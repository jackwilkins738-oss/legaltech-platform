# PI OPPORTUNITY MAP — FROM CASE ECONOMICS

## New opportunity ranking dimensions
Add to existing opportunity score:

### Cash-flow impact
Does automation release cash/disbursement sooner?

### Stage-economics impact
Could delay affect cost recovery or settlement economics?

### External dependency leverage
Does workflow involve a slow third party?

### Complaint-risk impact
Does it address communication/progression/cost transparency?
