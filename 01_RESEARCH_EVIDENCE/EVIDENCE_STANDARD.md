# EVIDENCE STANDARD

## Evidence labels
- VERIFIED FACT — authoritative/current documentation or directly verified behaviour
- REPEATED USER REPORT — same issue independently reported by multiple users/firms
- SINGLE USER REPORT
- OBSERVED WORKFLOW — directly observed in a real firm
- MEASURED RESULT — timing, count, log or financial calculation
- HYPOTHESIS
- ASSUMPTION
- DECISION

## Required fields
Claim, evidence label, source, date, version/environment, confidence, counter-evidence, implication, validation requirement, owner.

## Evidence hierarchy
1. Direct measurement/observation
2. Official current documentation
3. Multiple independent current users
4. Independent market evidence
5. Single user report
6. Founder assumption

## Anti-confirmation-bias rule
Actively seek Proclaim strengths, satisfied users, configuration-vs-product explanations, existing features that already solve the issue, competitor strengths, and reasons firms refuse to switch.
