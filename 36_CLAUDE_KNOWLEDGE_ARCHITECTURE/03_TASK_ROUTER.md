## Multi-domain rule
Security/privacy and evidence gates are cross-cutting. If a product/engineering task touches customer data, identity, files, AI actions, external communication or permissions, add the `security_privacy` route even if it is not the primary route.

## Unknown route
If no route fits, inspect `MASTER_PROJECT_INDEX.md` and `FILE_CATALOG.csv`, then create/update a route only if the class of work will recur.
