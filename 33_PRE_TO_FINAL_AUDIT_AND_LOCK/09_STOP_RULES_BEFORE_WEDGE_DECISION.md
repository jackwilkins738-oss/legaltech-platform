# STOP RULES BEFORE FINAL WEDGE DECISION

Do not select/build the production wedge until the candidate has:

## Operational evidence
- repeated real observations;
- specific Task Family definition;
- measured handling time;
- understood exception path.

## Volume evidence
- plausible independently sourced frequency;
- actual population/roles.

## Automation evidence
- judgement/exception profile;
- native Proclaim capability checked;
- technical feasibility plausible.

## Economic evidence
- capacity/cycle-time/risk value distinguished;
- review burden included;
- realistic realisation discount.

## External evidence
- pain repeated by unrelated firms or a clear reason the initial firm is a sufficiently valuable niche.

## Buying evidence
- budget owner identified;
- paid pilot path plausible.

A very painful task with no access path is not the wedge.
A highly automatable task with trivial value is not the wedge.
