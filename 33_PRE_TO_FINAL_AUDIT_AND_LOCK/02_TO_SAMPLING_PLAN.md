# TO SAMPLING PLAN

## Goal
Observe a representative slice of work without cherry-picking the current product thesis.

## Phase A — calibration
First 3 task events:
- learn task boundaries;
- confirm timing method;
- check taxonomy;
- confirm anonymisation.

Mark Sample Mode = `CALIBRATION`.
Do not use these timings for provisional ranking unless later reviewed and explicitly included.

## Phase B — continuous observation
Where operationally possible, observe 60–90 minutes continuously for a priority role.

Why:
Targeted observation overstates workflows the observer is looking for.
Continuous blocks reveal interruptions, low-value work and unexpected tasks.

Priority roles:
1. legal admin / administrative case support;
2. file handler / paralegal;
3. fee earner;
4. team leader when available.

If only one role is available, record that limitation. Do not generalise across the firm.

## Phase C — targeted repeats
After the continuous block, deliberately collect additional examples of repeated/high-potential task families.

Use Sample Mode = `TARGETED_REPEAT`.

## First-day target
- 30+ total events if operationally practical;
- 3+ roles if naturally available, but quality beats forced breadth;
- normal and exception cases;
- at least 5 measured examples before treating a Task Family × Role mean as provisional;
- 10+ is preferable for high-variance workflows.

These are internal analysis rules, not statistical proof thresholds.

## Time-of-day / workload bias
Log unusual conditions:
- unusually quiet/busy;
- training day;
- system outage;
- staff absence;
- deadline spike;
- unusual case type.

## Never do
- ask staff to manufacture examples;
- observe only inbound email because that is the current hypothesis;
- count waiting as active work;
- copy identifiable matter content;
- compare named employees as a performance league table.
