# SCALE / INVESTOR MODEL

## Venture-scale thesis
A narrow email-filing tool alone is not enough.

The large-company path is:

### Phase 1
Inbound legal operations

### Phase 2
Exception-based legal operations platform

### Phase 3
Workflow/document/task intelligence

### Phase 4
Canonical matter operating layer

### Phase 5
Migration tooling

### Phase 6
Full PMS replacement for suitable firms

## ARR scenarios

### 25 firms × £30k ACV
£750k ARR

### 100 firms × £50k ACV
£5m ARR

### 300 firms × £70k ACV
£21m ARR

### 1,000 firms × £80k ACV
£80m ARR

Illustrative, not forecasts.

## What investors/acquirers would value
- repeatable ARR
- low churn
- high NRR
- strong gross margin
- proprietary workflow data
- integration depth
- Proclaim migration engine
- certifications
- reference firms
- low services dependency
- clean IP
- defensible customer relationships

## What destroys scale
- bespoke code per firm
- founder-led implementation forever
- low ACV/high support
- weak security
- dependency on one fragile Proclaim integration
- no migration capability
- no standard data model

## Capital milestones
Raise only if capital materially accelerates:
- validated product
- repeatable sales
- migration/platform expansion
not to finance an unvalidated full PMS build.
