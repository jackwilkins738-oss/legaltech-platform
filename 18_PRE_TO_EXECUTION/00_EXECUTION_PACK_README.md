# PRE-TO EXECUTION PACK

## Purpose
Convert the research/scoping repository into work that can actually be executed before and during TO.

This pack is deliberately narrower than previous research.

It answers:
- What technical spike should be built?
- What exactly counts as pass/fail?
- What synthetic test data do we need?
- What should external interviews capture?
- What can be built if inbound operations wins?
- What evidence is required before moving from prototype to pilot?

## Execution tracks
1. Graph ingestion spike
2. Safe document pipeline
3. Proclaim adapter spike
4. Canonical event prototype
5. AI/evaluation harness
6. External validation interviews
7. Security abuse tests
8. Conditional V1 PRD

## Rule
A spike exists to answer a question, not to become production by accident.
