# PRE-TO SCOPING & DECISION PACK

## Purpose
Finish every useful decision framework **before** the Time-and-Motion study lands.

Tomorrow's observed data should not start a new research phase. It should be inserted into pre-defined models that answer:

1. Which workflow costs the firm the most?
2. Which workflow is realistically automatable?
3. Which workflow is safest to pilot?
4. Which workflow supports meaningful ACV?
5. Which workflow creates the strongest expansion path?
6. Which technical assumptions have to be proven before production build?

## What this pack contains
1. Opportunity scoring model
2. Proclaim technical validation matrix
3. TO analysis framework
4. Five highest-priority service deep dives
5. V1 screen specification
6. Pilot economics model
7. Buyer/procurement journey
8. External validation plan
9. Thesis red-team
10. Tomorrow decision gates
11. Parallel work plan

## Current working hypothesis
The leading wedge remains:

**Inbound communication/document → matter match → classification/extraction → proposed action → exception review → approved write-back → audit**

This is still a hypothesis.

## Rule
TO evidence can overturn any product hypothesis.

The goal of this pack is to make that overturning fast and rational rather than emotional.
