# PARALLEL WORK PLAN — WHAT HAPPENS WHILE TO RUNS

## Founder / commercial track
1. Build 20-account target list.
2. Identify 2–3 buyers per account.
3. Prepare interview outreach.
4. Conduct external interviews.
5. Collect actual pricing/procurement objections.
6. Build pilot candidate pipeline.

## Partner / branch track
1. TO observations.
2. Proclaim environment facts.
3. Obtain authorised API/docs/test access.
4. Identify internal Proclaim expert.
5. Capture examples of repetitive inbound work.

## Technical track
Synthetic/test data only until permissions exist.

1. Graph webhook prototype.
2. Safe file pipeline.
3. Canonical event model.
4. Mock Proclaim adapter.
5. Matter-match evaluation harness.
6. Basic exception queue prototype.

## Security/company track
1. Company-owned GitHub/email/cloud accounts.
2. MFA/passkeys.
3. branch protections.
4. secret manager.
5. vendor register.
6. minimum incident contacts.
7. DPA/pilot draft.
8. insurance broker research.

## Claude/repository track
1. Ingest TO data.
2. calculate economics.
3. update scorecard.
4. challenge assumptions.
5. update decision log.
6. maintain source/evidence labels.
7. prepare pilot spec once a winner emerges.

## Things explicitly NOT to build yet
- full PMS
- legal accounting
- huge client portal
- broad legal research
- dozens of AI agents
- international product
- expensive certification program

The fastest path is evidence → technical proof → paid pilot.
