# STOP / PIVOT CONDITIONS

## Stop inbound automation as primary wedge if
- observed frequency/value is low;
- most work is already well automated;
- human review consumes most proposed saving;
- multiple firms refuse acceptable integration access;
- strong Proclaim teams demonstrate the same result is trivial to configure natively.

## Stop Proclaim augmentation approach if
- safe/reliable supported write-back is unavailable;
- API entitlement is commercially impractical;
- customers will not permit integration;
- Evo displacement makes the integration window too short.

## Stop PI-first positioning if
another practice area demonstrates materially better:
- repetition;
- economics;
- technical feasibility;
- buyer urgency;
- pilot simplicity.

## Stop a pilot if
- cross-client confidentiality failure;
- serious security control failure;
- inability to reconcile writebacks;
- measured value is insufficient;
- sponsor/technical access disappears.

## Do not stop merely because
- one interview is negative;
- first model accuracy is poor;
- one firm has excellent native Proclaim configuration.

Those are evidence, not automatic market conclusions.
