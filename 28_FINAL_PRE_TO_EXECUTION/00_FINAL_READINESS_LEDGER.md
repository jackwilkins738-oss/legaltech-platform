# FINAL PRE-TO READINESS LEDGER

## DONE — can be completed without new external evidence
- market/competitor research;
- Proclaim desk research;
- PI/clinical workflow models;
- product/wedge hypotheses;
- long-term product architecture;
- security/privacy/AI governance design;
- commercial/pilot/procurement models;
- company ops/compliance templates;
- Claude Code engineering operating system;
- API/event/config reference contracts;
- synthetic corpus;
- TO Day-0 operating kit;
- external-validation execution kit;
- runnable synthetic technical spike harness;
- verified initial outreach contacts/routes;
- first-50 engineering task plan.

## BLOCKED BY TO / USER OBSERVATION
- actual task frequencies;
- active handling minutes;
- waiting times;
- exception/rework rates;
- exact user pain ranking;
- final wedge score.

## BLOCKED BY CUSTOMER / PROCLAIM ACCESS
- exact API entitlement;
- real auth method;
- endpoint behaviour;
- write/read-back semantics;
- rate/throughput limits;
- customer field mappings;
- restricted-matter configuration.

## BLOCKED BY EXTERNAL VALIDATION
- problem repeatability;
- buyer identity;
- willingness to pay;
- procurement friction;
- Graph/API-access acceptability;
- paid-pilot candidate.

## BLOCKED BY REPRESENTATIVE DATA
- model accuracy;
- OCR accuracy;
- auto-action threshold;
- acceptable review burden;
- real document-parser exception rate.

## BLOCKED BY QUALIFIED PROFESSIONAL REVIEW
- final customer contracts;
- final DPA/security schedule;
- regulated/high-impact automated-decision boundaries;
- any legal accounting/client-money feature;
- formal insurance/certification claims.

## Rule
Do not manufacture certainty in any blocked category. The next work is evidence collection or controlled technical testing.
