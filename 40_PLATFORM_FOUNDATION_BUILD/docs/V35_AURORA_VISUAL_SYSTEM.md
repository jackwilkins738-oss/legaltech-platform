# V35 — Aurora Enterprise Visual System

**Lifecycle:** current UX/operability layer.  
**Evidence status:** presentation only; does not alter legal/product evidence gates.

V35 replaces the accumulated browser presentation layer with the Aurora visual system while preserving V34 operator capabilities and the same authenticated API/security boundaries.

## Visible changes
- distinct secure-workspace sidebar and branded V35 shell;
- glass/telemetry top bar and control-fabric context rail;
- animated ambient grid, aurora field, scanline and live-state accents;
- redesigned command hero, metric surfaces and progression pipeline;
- denser priority queue and matter-state panels;
- redesigned three-pane Exception Review workspace for source evidence, AI/matching telemetry and matter context;
- upgraded decision controls, audit trace, matter timeline and tables;
- redesigned command palette, notification drawer, empty/loading/error surfaces;
- responsive fallbacks for narrower screens.

## Preserved controls
Search, filters, saved views, attention feed, safe bulk rejection, single-item approval, tenant-scoped reads, idempotency, human approval, mock Proclaim reconciliation and audit remain unchanged.

## Guardrail
Aurora must not visually imply that synthetic priority, confidence or progression state is validated legal risk, deadline authority or customer evidence. D-018 remains in force.
