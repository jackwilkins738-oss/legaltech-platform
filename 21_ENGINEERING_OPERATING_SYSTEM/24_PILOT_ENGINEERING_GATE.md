# PILOT ENGINEERING GATE

A real-customer pilot may begin only when all applicable items are evidenced.

## Product
- bounded workflow;
- baseline metric;
- human approval boundary;
- success/kill criteria.

## Integration
- Graph scoped/tested;
- Proclaim required capabilities tested;
- write/readback reconciliation;
- connector degraded mode.

## Security
- tenant isolation pass;
- authz pass;
- file quarantine pass;
- secrets in manager;
- logs/content minimised;
- incident process;
- backup + restore test.

## AI
- dataset versioned;
- eval results reviewed;
- no autonomous high-impact action;
- prompt-injection tests;
- provider data terms accepted.

## Operations
- monitoring;
- alerts;
- support owner;
- kill switch;
- rollback/degraded mode.

## Customer
- DPA/security schedule;
- named contacts;
- approved mailboxes/matters;
- authorised test/production actions.

Failure of critical gate means NO GO, not 'ship and fix later'.
