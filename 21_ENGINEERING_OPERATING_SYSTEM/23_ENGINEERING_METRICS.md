# ENGINEERING METRICS

## Delivery
- lead time per task;
- deployment frequency;
- change failure rate;
- rollback rate.

## Reliability
- job success;
- queue age;
- connector availability;
- write reconciliation rate;
- restore-test success.

## Quality
- escaped defects;
- security findings;
- AI regression failures;
- customer correction rate.

## Claude productivity
Track cautiously:
- task cycle time;
- first-pass CI success;
- review rework;
- defect rate by generated change.

Do not optimize for lines of code or number of Claude tasks completed.
