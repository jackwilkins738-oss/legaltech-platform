# ARCHITECTURE DECISION RECORDS

## When ADR required
- new infrastructure primitive;
- change persistence technology;
- service extraction;
- auth model;
- tenant model;
- workflow execution model;
- AI provider architecture;
- major proprietary platform dependency;
- irreversible data model decision.

## ADR format
- ID/title/date;
- status: proposed/accepted/superseded;
- context;
- options;
- decision;
- consequences;
- security/privacy impact;
- exit/reversal path.

## Rule
Claude may draft ADR.
Material ADR acceptance is human/founder/technical decision.
