# Pre-TO Engineering Stop Line

## Safe to continue
- dev tooling;
- tenant/security primitives;
- synthetic evaluation;
- observability;
- mocks/adapters;
- queue/idempotency;
- database prototypes;
- non-customer UI shell.

## Stop until evidence/access
- real Proclaim API implementation;
- firm-specific custom fields;
- final workflow automation;
- auto-action thresholds;
- customer mailbox permissions;
- production SSO/SCIM;
- real medical/legal document evaluation;
- pricing-coded product packaging.

A coding agent must not cross this stop line because there is spare engineering capacity.
